# 常见中文文档模板

以下模板基于通用技术文档结构整理，可按任务裁剪，不要求全部保留。

## README 模板

```markdown
# 项目名称

## 简介

## 功能特性

## 环境要求

## 安装

## 快速开始

## 常见用法

## 常见问题

## 许可证
```

适用场景：

- 开源项目首页
- 工具仓库说明
- 内部组件使用说明

## 教程 / 手册模板

```markdown
# 文档标题

## 简介

## 适用对象

## 前置条件

## 安装

## 设置

## 基础使用

## 进阶操作

## 故障处理

## 附录
```

适用场景：

- 部署文档
- 操作手册
- 培训材料

## API 文档模板

```markdown
# API 名称

## 概览

## 认证方式

## 请求地址

## 请求参数

## 返回结果

## 错误码

## 示例

## 备注
```

适用场景：

- HTTP API
- SDK 方法说明
- 内部服务接口文档

## 发布说明模板

```markdown
# 版本号

## 发布时间

## 变更摘要

## 新增功能

## 修复问题

## 不兼容变更

## 升级与迁移

## 已知问题
```

适用场景：

- 发布公告
- 版本更新记录
- 升级指引

## FAQ 模板

```markdown
# 常见问题

## 安装问题

## 配置问题

## 使用问题

## 权限问题

## 兼容性问题
```

适用场景：

- 客服知识库
- 产品帮助中心
- 团队内部支持文档

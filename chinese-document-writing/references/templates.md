# 常见中文文档模板

以下模板基于通用技术文档结构整理，可按任务裁剪，不要求全部保留。只保留有材料支撑的章节；未知的发布时间、参数、预期结果和恢复操作另列信息缺口，不补造内容。校对任务不按模板重构原文。

## README 模板

```markdown
# 项目名称

## 简介

## 功能特性

## 环境要求

## 安装

## 快速开始

## 常见用法

## 常见问题

## 许可证
```

适用场景：

- 开源项目首页
- 工具仓库说明
- 内部组件使用说明

## 教程 / 手册模板

```markdown
# 文档标题

## 简介

## 适用对象

## 前置条件

## 风险与限制

## 安装

## 设置

## 基础使用

## 进阶操作

## 故障处理

## 验证与恢复

## 附录
```

适用场景：

- 部署文档
- 操作手册
- 培训材料

操作步骤应先写条件与风险，再按执行顺序列出动作、已知的预期结果和失败时停止条件。详细规则见 [受控中文技术写作](controlled-technical-chinese.md)。

## API 文档模板

```markdown
# API 名称

## 概览

## 认证方式

## 请求地址

## 请求参数

## 返回结果

## 错误码

## 示例

## 备注
```

适用场景：

- HTTP API
- SDK 方法说明
- 内部服务接口文档

参数说明应覆盖已知的类型、必填性、单位、默认值、范围和缺省行为；状态码、字段和值保持原样。详细规则见 [API 状态与错误文案](api-status-copy.md)。

## 发布说明模板

```markdown
# 版本号

## 发布时间

## 变更摘要

## 新增功能

## 修复问题

## 不兼容变更

```

适用场景：

- 发布公告
- 版本更新记录
- 升级指引

## FAQ 模板

```markdown

## 安装问题

## 配置问题

```

适用场景：

- 客服知识库

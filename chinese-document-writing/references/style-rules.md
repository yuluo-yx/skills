# 中文文档风格规则

本文整理自阮一峰的仓库 `ruanyf/document-style-guide`，并针对技能使用场景做了压缩重组。

- 来源仓库：`https://github.com/ruanyf/document-style-guide`
- 访问日期：2026-04-08
- 适用范围：中文技术文档、README、使用手册、教程、接口文档、FAQ、发布说明

## 1. 标题

- 标题最多使用四级，常规文档尽量控制在三级以内。
- 一级标题下不能直接出现三级标题，层级必须连续。
- 避免孤立编号；如果某一级只有一个子标题，通常应收拢结构。
- 下级标题不要重复上级标题名称。
- 标题末尾不加句号、逗号、顿号、分号、冒号。

推荐：

```markdown
# 安装指南

## 环境要求

## 安装步骤

### macOS

### Linux
```

## 2. 文档结构

对较完整的软件文档，优先采用下列结构进行取舍：

- 简介：说明产品定位、目标读者、文档范围。
- 快速上手：给出最短使用路径。
- 入门篇：环境准备、安装、设置、基础用法。
- 进阶篇：高级场景、开发扩展、性能与调优。
- API：接口、参数、返回值、错误说明。
- FAQ：常见问题。
- 附录：术语表、最佳实践、故障处理、版本说明、反馈方式。

文档文件名遵守以下规则：

- 不含空格。
- 使用半角字符，不使用中文文件名。
- 默认小写。
- 多词之间用 `-` 分隔。
- 特例文件可使用 `README`、`LICENSE` 等惯例大写名。

## 3. 句子与措辞

- 优先使用短句。单句尽量控制在 20 个字左右，超过 30 个字时要确认语义仍然清楚。
- 优先使用简单句和并列句，少用多层嵌套的复合句。
- 优先使用肯定句，不用双重否定。
- 优先使用主动语态，不用被动语态。
- 使用现代汉语常用表达，不用生造词、文言词或过度书面化表达。
- 代词必须指代明确，避免“其”“该”“此”指向不清。
- 名词前不要堆叠过多形容词。

改写方向：

- 不清楚的句子改为“主语 + 动作 + 结果”。
- 复杂说明改为“前置条件 + 操作步骤 + 输出结果”。
- 抽象描述改为可执行表述。

## 4. 段落

- 一个段落只表达一个主题。
- 中心句放在段首，后文围绕中心句展开。
- 段落长度不超过七行，最佳长度不超过四行。
- 段落之间空一行。
- 段首不空两格，不插入无意义缩进。
- 叙述语气保持平实、陈述、肯定，避免口号式和感叹式表达。

## 5. 中英文、数字与空格

- 全角中文字符与半角英文字符之间保留一个半角空格。
- 全角中文字符与半角数字之间可以留空格，也可以不留，但同一文档必须统一。
- 数字与英文单位之间保留空格，如 `16 GB`、`1 h`。
- 半角英文或数字与中文全角标点之间不留空格。
- 阿拉伯数字一律使用半角数字。
- 四位以上数值使用千分号，如 `12,500`。
- 货币写法用阿拉伯数字，并在前面加货币符号或后面写中文货币名称，如 `$1,000`、`1,000 美元`。
- 数值范围使用 `～` 或 `—`，必要时两个数值都带单位，如 `67%～89%`。
- 表示变化时区分“增加了”和“增加到”、“降低了”和“降低到”。
- 不写“减少 N 倍”或“降低 N 倍”，改写为“减少百分之几”。

## 6. 标点

- 中文句子使用全角标点。
- 整句英文使用半角标点。
- 句号、逗号、顿号、分号、冒号等点号不得出现在标题末尾。
- 逗号不要“一逗到底”。
- 中文并列项使用顿号 `、`，最后一项可用“和”连接。
- 中文引用使用全角双引号 `“ ”`；引号内再引时用单引号 `‘ ’`。
- 补充说明使用全角圆括号 `（）`，括号前后不加空格。
- 说明列表前使用全角冒号 `：`；时间写法用半角冒号，如 `8:00`。
- 省略号使用 `⋯⋯`，不要使用 `...` 或 `。。。`。
- 避免使用感叹号，更不要连用多个感叹号。
- 连接复合名词或图表编号时用半角连字符 `-`，如 `图 1-1`。

## 7. 英文与专有名词

- 英文首次出现时，必要时给出中文说明或中英文对照。
- 后续再出现时可直接使用统一缩写。
- 专有名词使用正确大小写；普通名词不要随意首字母大写。
- 英文省略号翻成中文时改为 `⋯⋯`。
- 英文作品名翻成中文时，用书名号《》。
- 英文复数翻成中文时，通常还原为单数概念表达。

## 8. 引用与来源

- 直接引用第三方内容时标明作者与来源。
- 整篇转载需在文首显著位置说明出处并链接原文。
- 外部图片需在图下注或文末标注来源。
- 技术参数、版本行为、标准规范等信息，优先附上官方链接或文档来源。

## 9. 写作原则总结

可以把整份文档的判断标准压缩成六个词：

- 结构清楚
- 标题连续
- 句子简洁
- 术语一致
- 标点规范
- 引用可追溯
